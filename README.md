# 🎮 MODS RECOMP

**Mods for Video Game Decompilations & Recompilations**

Welcome to **MODS RECOMP**, a repository dedicated to creating and sharing modifications for video game decompilation and recompilation projects.

## 🛠️ About This Project

MODS RECOMP aims to enhance the gaming experience through various modifications, including graphical improvements, visual enhancements, gameplay adjustments, and other features.

The project covers multiple gaming platforms and is not limited to Nintendo 64 recompilations.

## 🐧 Platform Compatibility

**Steam Deck & Linux — Primary Platforms**

All modifications are primarily developed, tested, and optimized for Steam Deck and Linux environments.

**Windows — Experimental Support**

Windows compatibility is considered experimental. Some modifications may work correctly, but full functionality and stability are not guaranteed.

## 🎯 Project Goals

- Enhance existing decompilation and recompilation projects.
- Improve visual quality and gameplay experiences.
- Prioritize Steam Deck performance and Linux compatibility.
- Explore new possibilities offered by native PC recompilations.
- Provide accessible modifications for the gaming community.

## ⚠️ Disclaimer

Compatibility and performance may vary depending on the game, recompilation project, operating system, and hardware configuration.

MODS RECOMP is an independent community project and is not affiliated with any console manufacturer or game publisher.
